# Relaybot Privacy Policy (GitHub Pages)

Public privacy policy for App Store Connect. Matches the in-app policy.

## Publish (free)

1. Create a public GitHub repo named `relaybot-privacy` (or any name).
2. Upload `index.html` (and this README) to the repo root (or `docs/`).
3. Repo **Settings → Pages → Deploy from branch → main → / (root)** → Save.
4. After a minute, open:
   `https://<your-github-username>.github.io/relaybot-privacy/`
5. Paste that URL into App Store Connect → App Privacy / Privacy Policy URL.

No paid domain required.
